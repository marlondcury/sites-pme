# sites-pme — Landing Page (Marlon Domingos)

Site institucional/landing page para divulgação do serviço de criação de sites para pequenas e médias empresas.

## Estrutura do projeto

```
sites-pme/
├── index.html            # marcação HTML (semântica, SEO, schema.org)
├── assets/
│   ├── css/
│   │   └── style.css     # todos os estilos
│   ├── js/
│   │   └── main.js       # menu mobile (abrir/fechar)
│   └── images/
│       └── favicon.svg   # ícone do site
├── robots.txt             # instruções para buscadores
├── sitemap.xml             # mapa do site para SEO
├── .nojekyll                # impede o GitHub Pages de processar via Jekyll
└── README.md
```
